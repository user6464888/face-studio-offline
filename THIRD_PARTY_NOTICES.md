# Third-party components and resources

The repository MIT license applies to project-authored code and the analytic mannequin generator. Dependencies, optional models, SDKs and user inputs retain their own terms.

## Included browser code

`head_reconstruction/viewer/vendor/` contains [Three.js](https://github.com/mrdoob/three.js), its PLY loader and OrbitControls. The original source headers and full [MIT license](head_reconstruction/viewer/vendor/THREE-LICENSE.txt) are retained.

## Python dependencies

Dependencies are installed through pip. Principal demo dependencies are NumPy (BSD), SciPy (BSD), trimesh (MIT), Open3D (MIT) and NetworkX (BSD). Optional reconstruction uses OpenCV, Pillow, scikit-image, PyTorch, ONNX Runtime, mapbox-earcut, Rtree and Shapely. Consult each distribution for its complete license and bundled notices.

## Optional tools and models

- [Orbbec SDK](https://github.com/orbbec/OrbbecSDK): the included ctypes bridge targets SDK 1.8.3. Obtain its runtime separately under the upstream terms.
- [COLMAP](https://github.com/colmap/colmap): executable builds are installed separately; check build-specific feature and CUDA support.
- YuNet, BiRefNet, ALIKED/LightGlue and optional 3DDFA/BFM models: weights and downloaded inference code are not included. Review upstream code, weight and data licenses independently. BFM-based refinement is optional and is not required by the demo.

## Research references

Liwen Hu, Chongyang Ma, Linjie Luo and Hao Li, *Single-View Hair Modeling Using A Hairstyle Database*, SIGGRAPH 2015, provides relevant background on hair databases. [USC-HairSalon data](https://huliwenkidkid.github.io/liwenhu.github.io/) has separate non-commercial and redistribution restrictions; the repository includes no USC head meshes, modified dataset meshes or hair data.

Historical hair compatibility readers refer to [Cem Yuksel's hair models](https://www.cemyuksel.com/research/hairmodels/) and Murat Afshar's reference head. These data files are not included or required by the 19-style generator.

## Geometry, images and local inputs

The default mannequin is generated by `salon/procedural_head.py` from analytic profiles and primitives. Documentation images show project-rendered geometry. External reference photographs, participant recordings, identifiable face geometry and skin textures are not included. Users are responsible for obtaining permission and checking terms for their own inputs and any added resources.
