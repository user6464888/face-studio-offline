# 更好的标准头：获取与适配

项目默认使用原创数学头模，无需额外下载；五官和耳朵比较简化。需要更完整的面部细节时，可以使用下列来源的基础头模并完成适配。

以下是替换候选和操作路线，**尚未在本项目下载、导入或验证**。外观更自然的预期来自模型用途，实际贴合效果仍须检查。

## 优先候选：Blender Human Base Meshes

来源：[Blender 官方 Demo Files 的 Asset Bundles](https://www.blender.org/download/demo-files/)。核对日期 2026-10-27：`Human Base Meshes v1.4.1` 条目标注 49 MB、CC0，要求 Blender 4.2 LTS 或更新版本。这个页面同时有其他许可的资源，应核对具体条目，不能把页面上所有素材都当成 CC0。

建议流程：

1. 在 Asset Bundles 中获取 Human Base Meshes，保留下载页、版本和随包说明。
2. 在 Blender 中选择中性表情、闭口、无头发的头部或人体基础网格。优先保留头皮、耳朵、下巴和一小段颈部；不要只截取前半张脸。
3. 如资源是全身模型，分离头颈；清理重复面、异常法线和与头部无关的物件。面数较高时保留原文件，另做演示用简化副本。
4. 导出适配用 PLY／OBJ；不要把 `.blend` 改个扩展名当成 PLY。
5. 按下方坐标、尺寸与区域要求接入项目，并逐视角检查。

若目标只是提升演示的基础五官和头部完整度，这是较直接的路线。

## 参数化候选：MakeHuman／MPFB

[MakeHuman Community](https://www.makehumancommunity.org/) 提供 MakeHuman；[MPFB](https://www.makehumancommunity.org/mpfb/index.html) 是 Blender 内的人体角色生成工具。可生成中性角色，通过参数改变额宽、颧部、下颌、下巴和脸长，再导出头颈网格。

官方 [许可说明](https://www.makehumancommunity.org/about/license.html) 将核心图形资产标为 CC0；程序代码许可与图形资产不同。第三方下载的社区头发、衣服、贴图和其他资产需分别核对许可。使用仅含核心资产的无发角色，可以减少演示的素材来源复杂度。MakeHuman [支持的导出格式](https://www.makehumancommunity.org/makehuman/docs/exports_and_file_formats.html) 包括 OBJ。

建议先制作一个完整中性头，然后保持拓扑和姿态一致地制作七个示意变体；不应把某组参数描述成“经过验证的七种标准人群脸型”。

## 导入本项目还要做什么

目前没有网页上传任意标准头的入口，也不能只覆盖一个网格文件。新模板需要一个准备适配步骤：

| 项目 | 适配要求 |
|---|---|
| 坐标 | 本项目使用 X 左右、Y 向上、Z 面朝前；Blender 通常 Z 向上，必须转换坐标并应用变换 |
| 尺寸 | 统一按米使用；为头皮定义合理 `centre` 和 X/Y/Z `radii`，不要以整个全身包围盒作为头部尺寸 |
| 形态 | 中性表情、无原有头发、耳朵和后脑完整；颈部截口可以保留 |
| 网格 | 三角化、有限坐标、正确法线；避免眼球或口腔内部成为发根投射的最近表面 |
| 区域 | 根据新耳朵位置重建耳区保护，核对前额发际线与后颈生发范围 |
| 贴合 | 从新模板重新生成径向场、掩码、几何指纹与发型缓存，不能沿用旧模板的 NPZ／PLY 缓存 |
| 七种脸型 | 可在同一基底上变形，但变形参数要重新观察；当前数学头参数未必适合另一种模板 |
| 颜色 | 标准头显示当前读取网格顶点颜色。若要保留外部皮肤纹理，还需完善 UV／材质加载，不能假定替换 OBJ 会自动带上纹理 |

实现位置为 `salon/procedural_head.py`（模板来源）与 `salon/heads.py`（标准头准备、测量、耳区及贴合场）。更换模板时应更新演示准备版本以重建依赖；不要只修改显示名称。

接入后最少检查正面、左右侧、后脑、头顶，以及短发、中分、碎盖和辫束。需要同时检查发根贴合、耳周漏发和头旋密度；仅能加载或面数检查通过，不代表视觉适配完成。
