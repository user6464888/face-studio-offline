# v0.1.0

Face Studio 是一个离线人头重建与发型试戴研究原型。

## 功能

- 19 款程序化发型与七种示意脸型，任意组合试戴。
- 短发曲面、中长度发束和外层长发丝／辫束三层结构，支持独立开关。
- 发色、视角、自动旋转及 PNG 图片保存。
- 基于手工规则的选款建议和打理说明。
- 默认运行无需相机的数学头模演示；显式指定主录像和顶部补拍可运行实验性重建。

## 环境

演示已在 Windows x64、Python 3.11.7 环境验证。完整重建需要相应 SDK、权重和外部工具，见 [重建设置](RECONSTRUCTION.md)。服务仅监听本机；GitHub Pages 无法运行 Python 后端。

## 已知限制

头模、隐藏头皮和发型包含估计；脸型建议没有经过标注人群验证。程序不承诺照片级真实感、精确颅骨分析、任意素材重建成功或跨平台兼容。界面暂不提供发型 GIF／GLB 导出。

具体检查范围见 [验证记录](VALIDATION.md)。
